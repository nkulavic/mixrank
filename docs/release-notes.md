Company-to-contact workflow across the Go SDK, native CLI (`mixrank contacts`) and MCP (`mixrank_company_contacts`). Finds current relevant people and returns available business emails and direct dials with source dates, review flags and explicit gaps.

Accepts company JSON exports and raw search results; supports role filters, bounded calls, private JSON output and partial results. All 102 provider operations remain available. Skills now carry lead generation through contact discovery.

Contact data is provider-reported and email validation is separate. Hosted OAuth, Vercel deployment and Cowork live connector activation remain deferred. See docs/contacts.md and docs/validation.md.
